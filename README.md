## 🛠 Built with

**React 19**, **Vite**, **JavaScript** and **CSS**, with **ESLint** and automated deployment through **GitHub Actions / GitHub Pages**.

## 🎮 Bull vs Bear

An original, pixel-art browser mini-game. Move with **A / D** or **← / →**, jump with **W / Space / ↑**, and drop through platforms with **S / ↓**. Collect **15 candlesticks** to win.

*Game Mode is available on desktop only.*

## 🛠 Set-up

1. **Install the dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```
   Open the local URL shown in your terminal (usually `http://localhost:5173/`).

## 🚀 Build and run for production

1. **Build the production site**
   ```bash
   npm run build
   ```

2. **Preview the production build locally**
   ```bash
   npm run preview
   ```

The production files are generated in `dist/` and deployed to GitHub Pages via GitHub Actions.
